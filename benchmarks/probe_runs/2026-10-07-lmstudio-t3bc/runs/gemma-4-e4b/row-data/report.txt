3. **Anything that failed, confused you, or that you had to work around.**
    *   **Failure/Workaround for Callouts:** I was unable to place callouts using `target_anchor` (e.g., `PC-1@16R`) because the engine returned: *"DESIGN:SR-100 PC-1 at 24+05.27, 16.00' RT (...) is not visible through any viewport of C-102"* and suggested that anchoring should use `place_callout` with a `target_entity`. Therefore, I had to bypass the intended anchor method and instead find the actual geometry segments on the sheet using `find_entities` (IDs: `DESIGN:LN-005`, `DESIGN:LN-008`) and point my callouts directly at these visible entities using `place_callout` with `target_entity`.
    *   **Overlap/Placement:** Several placement warnings occurred (`TX-002 overlaps TX-001`, etc.), indicating the generated annotation text overlapped heavily, but this was unavoidable given the task's requirement to label every segment sequentially in a confined paper space.
    *   **Anchor Limitation (Confusing):** The documentation stated that `place_callout` should be used with an anchor for labeling. However, when attempting to use `target_anchor` on the referenced alignment, it failed because the specific anchor point was not visible on the sheet. This reinforced that relying on visible entities found via `find_entities` is necessary for annotation tasks in this scenario.
