**3. Anything that failed, confused you, or that you had to work around:**
The primary difficulty was placing design-anchored labels and callouts directly onto an alignment (`DESIGN:SR70`) which is explicitly marked as a **reference attachment**. The engine correctly throws errors:
*   When attempting `place_label` or `place_callout`, the error message was consistently: `"the document has no alignments"` (if run in model space) or, more specifically when running on a sheet: `"DESIGN:SR70 PC-1 at 570+43.42 (...) is not visible through any viewport of L-2"`.
*   This confirms that the engine prevents placing permanent, anchored labels from an external reference directly onto a sheet view without manually specifying coordinates and assuming visibility, or by calling out with `place_callout` using model space geometry rather than anchor points.

I worked around this by:
1.  Using `get_design_data` to extract all raw numbers (stations, $\text{R}, \Delta, \text{T}, \text{L}$) and then manually calling `place_table` to construct the required table structure in paper space.
2.  Ignoring the failures of the automated label/callout placement tools for anchored points and instead using general `place_text` commands at visually estimated coordinates near the curve centers, which is the best available method given the "reference only" status of the source alignment within the sheet file L-2.
