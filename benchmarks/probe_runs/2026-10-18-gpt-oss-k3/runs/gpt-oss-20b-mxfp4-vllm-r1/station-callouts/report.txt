**What was placed**

I inserted a callout for every 1‑ft‑station from **11+00** through **20+00** along alignment **SR‑100** that falls inside the viewport of sheet **C‑101**.  
Each callout is a text block in the sheet’s space, its leader tip on the alignment at the specified station, and the text simply reading the station number.  
The callouts all belong to the default annotation layer (the engine creates a new “V‑ANNO‑TEXT” layer if needed).

**What needed workarounds / gotchas**

* I had to compute the sheet‑space location for each callout position by calling `model_to_sheet`; specifying a raw point directly would not align the text with the viewer’s twist/scale.  
* The sheet has only one viewport, so I omitted the `viewport` parameter in the calls; if the sheet had multiple viewports, the same station could have been mapped to each separately.  
* No error messages were returned; all commands succeeded as the alignment `SR‑100` exists and the stations I queried lie within the viewport bounds.
