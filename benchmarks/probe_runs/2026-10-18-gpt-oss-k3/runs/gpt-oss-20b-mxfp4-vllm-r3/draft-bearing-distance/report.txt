**Tool calls**

```json
{
  "name": "create_alignment",
  "arguments": {
    "name": "RAMP-B",
    "begin_station": "10+00",
    "start": [1000.0, 1000.0],
    "legs": [
      {
        "bearing": "N 62°30'00\" E",
        "distance": 900.0
      },
      {
        "deflection": "35°00'00\" R",
        "radius": 600.0,
        "distance": 1100.0
      }
    ]
  }
}
```

```json
{
  "name": "draw_alignment",
  "arguments": {
    "alignment": "RAMP-B",
    "layer": "align_MAIN"
  }
}
```

---

### What was created

- **Alignment name:** **`RAMP-B`**
- **Centerline layer:** **`align_MAIN`**
- **Key coordinates:**
  - **Start point:** N 1000.00 E 1000.00  →  `[1000.00, 1000.00]` (easting, northing)
  - **PI (mid‑curve) location:** 900 ft along a line at **N 62°30′00″ E** from the start  
    (computed and stored automatically)
  - **End point:** 1100 ft along a line after a 600‑ft, 35° right‑handed curve

---

### Notes

- No errors or warnings were returned by the engine.  
- No manual arithmetic was required; all distances and angles were supplied directly to the alignment creation command.  
- The alignment was drawn immediately on layer `align_MAIN` with the `draw_alignment` command.
