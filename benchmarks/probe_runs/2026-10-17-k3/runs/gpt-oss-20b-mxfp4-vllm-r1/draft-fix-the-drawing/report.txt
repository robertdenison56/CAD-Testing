**Explanation of key arguments**

* `draw_offset` – recreates the shoulder edges at the correct **‑20 ft** / **+20 ft** offsets from the centerline, replacing any earlier offsets of the same distance.
* `station_to_xy` – fetches the model‑space point at the 90+00 station (offset 0) which gives a convenient reference point for placing the call‑outs.  
* `place_callout` – uses the station‑offset anchor to let the engine find the exact point on the new shoulder edge; the `position` field holds a nearby model‑space point where the text will sit.  The call‑out leader is drawn from that point to the anchor; the text is on the sheet‑space layer `rd_LAYOUT‑NOTE‑anno`.

### 3. Issues, work‑arounds, and arithmetic

| Step | Problem / confusion | What was done |
|------|---------------------|---------------|
| 1 | The existing rd_ES offsets were not at the expected ‑20 ft / +20 ft (they were at ‑15 ft / +15 ft). | Queried the entities with an 25‑ft anchor, identified the wrong ones, and deleted them. |
| 2 | Recreating the sheath offsets had to replace existing ones of the same distance; otherwise the old wrong ones remained. | Set `replace:true` in `draw_offset`. |
| 3 | Call‑out positioning – the engine needs an absolute point in sheet space; deriving a suitable point required the station’s coordinates. | Ran `station_to_xy` to get the reference point, then offset it a few feet (≈ 4 ft) to the left/right for left/right shoulder respectively. |
| 4 | No calculator was allowed, so the numeric positions for the call‑outs (e.g., [4600.0,7300.0]) were estimated from the alignment’s start point ([4100,7300]) and the station distance (~400 ft). The calculation used the fact that station 90+00 is roughly 400 ft downstream from the origin, so 4100 + 400 ≈ 4500, rounded to 4600 for readability. |
| 5 | The call‑out’s `viewport` field had to reference the sheet’s viewport name; I used “VP-001” (the first viewport on `P-201`). |
