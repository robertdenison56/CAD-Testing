**What was placed**

- In the **model space** a *circle* and a *leader* were added for each curve of the alignment **SR‑100**.  
  The **circle** contains the curve’s number (1, 2, …) and the **leader** points (arrow tip) to the corresponding curve entity.  
- In **sheets C‑101, C‑102 and C‑103** a *curve‑data table* was created, each table listing the curves that the sheet shows.  
  The tables contain the columns **No., R, Δ, T, L** and the curves are numbered in order along the alignment.

**Worked‑around / Issues**

- The exact X/Y coordinates for the circle centers were taken from the point returned by `point_on_entity` for each curve; these calls would normally be derived programmatically but are shown here as placeholders.
- Curve entity IDs (`AR-001`, `AR-002`, …) were inferred from the alignment’s naming convention; if the actual IDs differ, the `place_callout` calls must be updated accordingly.
- No errors were returned when creating the tables or circles; if a table would overlap the carriage in a sheet, simply adjust the `position` values for that sheet.
