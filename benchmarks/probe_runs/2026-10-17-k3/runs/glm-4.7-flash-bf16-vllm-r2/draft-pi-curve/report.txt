## Report

### 1. What was created and drawn
- **Alignment SR-9** was created (design model, U.S. survey feet)
  - Begin station: 50+00.00
  - End station: 74+38.37
  - 3 elements: 2 tangents, 1 curve with 800 ft radius
  - Begin point: (1000, 1000)
  - PI-2 (2200, 1000, 800 ft radius curve)
  - End point: (3100, 1900)
- **Centerline linework** drawn on layer `align_MAIN`
  - 2 line segments (LN-001, LN-002)
  - 1 arc (AR-001)

### 2. Tool calls that mattered
1. **create_alignment** — created the alignment design using the pis format:
   ```json
   {
     "name": "SR-9",
     "begin_station": "50+00",
     "pis": [[1000, 1000], [2200, 1000, 800], [3100, 1900]]
   }
   ```
2. **draw_alignment** — rendered the design as linework in model space on the requested layer:
   ```json
   {
     "alignment": "SR-9",
     "layer": "align_MAIN"
   }
   ```

### 3. Failures, confusion, and workarounds
- **Error:** `turn goes with deflection` when trying to use a curve with `radius` and `turn` on the same leg. Workaround: switched to the `pis` array format, which allows the radius on a PI coordinate.
- **Error:** `start and legs go together: legs run from start` when providing both a `start` point and a `legs` array. Workaround: omitted `start` and used the `pis` array instead, which defines the points and radii directly.
- **Error:** `Additional properties are not allowed ('length' was unexpected)` when trying to include an arc length. Workaround: removed that property and let the engine calculate the bearing and distance internally from the geometry.
