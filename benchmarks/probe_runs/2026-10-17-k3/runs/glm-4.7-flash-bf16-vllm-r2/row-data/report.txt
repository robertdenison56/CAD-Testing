## 3. Issues and workarounds

- **Initial anchor query failed** because I incorrectly formatted the JSON object for the `anchor` parameter. Fixed by using proper JSON syntax: `{"kind": "offset", "offset": [10, 10]}`.
- **label_segments initial attempt** failed with a parameter error because I used a non-existent `text_style` parameter; the tool accepts `style` which must be either "values" or "tags".
- **Missing table parameter** when first trying `style="tags"` - the tool requires a `table` object with a `position` to display the geometry values.
- **Warning about overlapping callouts** – TX-014, TX-016, TX-017, and TX-018 overlap with other callouts (TX-004, TX-008, TX-009, TX-005), which is unavoidable given the dense linework in this section.
