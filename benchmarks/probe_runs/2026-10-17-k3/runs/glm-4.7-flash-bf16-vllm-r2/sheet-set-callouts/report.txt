### Issues and workarounds:

1. **Manual sheet point calculation**: The `at="mid"` parameter worked for target_entity but I needed to manually compute where on the sheet the callout should sit using `model_to_sheet`. The API doesn't automatically place the text at a visually clear position alongside the target.

2. **Overlapping callouts on C-101**: Created duplicate callouts (TX-001/003 and TX-002/004) that overlapped. The system warned about this but didn't block execution. I could have consolidated but this provides redundancy which some workflows might want.

3. **Model-to-sheet conversion**: Had to look up `sheet_point` values from `find_entities` results rather than relying on the engine's automatic placement.

4. **Drafting geometry visibility**: The edge linework (especially arcs) are only partially visible on the third sheet; the callouts still point to the correct entities but the text appears outside the viewport boundaries.

5. **Not all offset layers**: Initially tried to filter by offset type, but the more direct approach was to find by layer (`rd_EP`, `rd_ES`) which was simpler and worked correctly.
