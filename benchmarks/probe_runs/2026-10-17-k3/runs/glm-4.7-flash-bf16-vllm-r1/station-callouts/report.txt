Report:

1. **What I placed**: Fifteen callout labels (TX-001 through TX-015) in sheet C-101 (paper space), each reading the station number (11+00 through 25+00) with leaders pointing to the centerline of referenced alignment DESIGN:SR-100 at those exact stations.

2. **Tool calls that mattered, in order**:
   - `get_document_state` - to see document structure
   - `list_references` - to locate the DESIGN basefile with SR-100
   - `list_alignments` with `include_references=true` - to find the alignment name
   - `get_sheet_state` for C-101 - to see viewport view range and sheet coordinates
   - `create_layer` V-ANNO-TEXT - needed because the requested layer didn't exist
   - `set_current_layer` V-ANNO-TEXT - to ensure new callouts use that layer
   - `place_callout` × 15 - for stations 11+00, 12+00, 13+00, 14+00, 15+00, 16+00, 17+00, 18+00, 19+00, 20+00, 21+00, 22+00, 23+00, 24+00, 25+00

3. **Anything that failed, confused me, or that I had to work around**:
   - **Parameter error**: Initially tried to use `side='below'` in `place_callout`, but the API schema does not support the `side` parameter (the error message explicitly stated "Additional properties are not allowed ('side' was unexpected)"). Removed it and the command worked.
   - **Layer missing**: Placed callouts using a layer name `V-ANNO-TEXT` that didn't exist. Created the layer first using `create_layer` with color, linetype, and description, then set it as current.
   - **Coordinate calculation**: I had to use `station_to_xy` to get model-space points and `model_to_sheet` to convert them to paper inches on C-101, rather than guessing viewport coordinates. The sheet_point values were crucial.
