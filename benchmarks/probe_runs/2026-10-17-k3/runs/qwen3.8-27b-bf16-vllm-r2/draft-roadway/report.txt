- No coordinates were hand-computed for the drawing (the alignment engine did the COGO), but I cross-checked by hand: first bearing S 80°E → azimuth 100°; PI-1 = 1000 + 800 sin100° = 1787.85 E, 3000 − 800 cos10° = 2212.15 N; T₁ = 500 tan20° = 181.98 → PC-1 = 1000+800−181.98 = 16+18.02; L₁ = 500·40°(π/180) = 349.07 → PT-1 = 19+67.08 (so the first PI lands exactly on 18+00.00, as the engine reports); bearing after 40° left = N 60°E; PI-2 = 1787.85 + 700 sin60° = 2394.06 E, 2212.15 + 700 cos60° = 3212.15 N; T₂ = 700 tan12.5° = 155.19, L₂ = 305.43 → PC-2 23+29.91, PT-2 26+35.34, end = 26+35.34 + (600−155.19) = 30+80.16. All match the engine's output to the centesimal foot.
