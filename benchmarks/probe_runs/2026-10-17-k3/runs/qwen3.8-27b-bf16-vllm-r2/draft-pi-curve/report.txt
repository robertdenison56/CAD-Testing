## 3. Failures / workarounds / arithmetic

- **One failure**: `create_layer {name: "align_MAIN"}` → `layer 'align_MAIN' already exists`. Workaround: nothing needed — the layer was already in the document, so I drew directly onto it.
- No coordinates were computed by me. The engine derived the curve from the PIs; I verified the chain by hand from its output, not before it:
  - First tangent 1000 → 2200 = 1,200 ft; curve T = R·tan(Δ/2) = 800·tan(22.5°) = 331.371, so PC = 1200 − 331.371 = 868.629 ft along → x = 1000 + 868.629 = 1868.629, matching LN-001's end and the arc center x.
  - Δ = 45° (east-bound tangent turning left onto a NE-bound tangent — the PI at (2200,1000) is the intersection of y = 1000 and the line through (3100,1900) at 45°, which indeed is (2200,1000) since 3100 − 2200 = 900 = 1900 − 1000).
  - PT at 45° from PC: 1868.629 + 800·sin45° = 1868.629 + 565.685 = 2434.315; 1000 + 800·(1 − cos45°) = 1000 + 234.315 = 1234.315 — matches LN-002's start.
  - L = Δ·R/57.3 ≈ 628.319; second tangent 1,200 − 331.371 = 868.629… wait — LN-002 measures 941.421: PT→end = √(900² + 900²) − 612.293 (chord) + … actually simply 1,200 (PI to end along the 45° line: √(900²+900²) = 1272.79 from PI) − 331.371 = 941.421. Total: 868.629 + 628.319 + 941.421 = 2,438.37 ✓.
