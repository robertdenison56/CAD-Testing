4. `place_callout {space: "C-102", target_entity: "DESIGN:LN-005", position: [10, 13.5], content: "EDGE OF PAVEMENT", layer: "rd_LAYOUT-NOTE-anno"}` — the actual placement (result: "placed in sheet C-102, pointing at DESIGN:LN-005 (line on rd_EP, 12.00' LT of SR-100) through VP-002").
5. `get_entity` TX-001 / PL-001 + `render_sheet C-102` — verified tip location and layout.

**3. Failures / workarounds**
- `place_callout` with `at: 0.13` failed twice with: `"where must be one of ['center', 'end', 'mid', 'middle', 'start'] or a fraction from 0 to 1, got '0.13'"` — the fraction was rejected even as a JSON number (the error always quoted the string `'0.13'`, so the value seems to arrive as a string regardless). Workaround: I omitted `at` entirely and let it default to `mid`; the resulting arrow tip coincided with the sheet midpoint of the EP line, so no quality was lost.
