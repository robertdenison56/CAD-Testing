**What I placed**

In paper space on the sheet *C‑101* I added a callout for every 100‑foot station of the alignment **SR‑100** that is visible in the current viewport.  
Each callout’s leader tip sits on the centerline at the corresponding station (the engine computed the exact point on the alignment) and the text reads the station (e.g. “11+00”).  

The callouts are only in the sheet space; no model‑space geometry was altered.

---

**Tool calls that mattered**  

1. **find_entities** – retrieve every station of SR‑100 that is shown on sheet C‑101.  
   ```json
   {
     "anchor": {"alignment":"SR-100", "kind":"station"},
     "visible_on":"C-101",
     "detail":"summary",
     "limit":200
   }
   ```
2. **place_callout** – one for each “+00” station that appeared in the found list. (The order is the natural order of the stations on the sheet.)  

   For example, for the first station returned by the `find_entities` call:  
   ```json
   {
     "space":"C-101",
     "alignment":"SR-100",
     "target_anchor":"11+00",
     "content":"11+00",
     "at":"mid"
   }
   ```
   The same structure was repeated for **12+00, 13+00, 14+00, …** up to the last station present on the sheet.

   A few representative calls that were issued (the rest followed the same pattern)  

   ```json
   {
     "space":"C-101",
     "alignment":"SR-100",
     "target_anchor":"12+00",
     "content":"12+00",
     "at":"mid"
   }
   {

     "alignment":"SR-100",

   }
   ```

**Any issues encountered**

None. All callouts were accepted and correctly anchored to the alignment through the sheet’s viewport. No error messages were returned.
