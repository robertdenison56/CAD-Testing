**What was placed**

- On **C‑101, C‑102 and C‑103** a *CURVE DATA* table was added (columns No., R, Δ, T, L) showing every curve of **SR‑100** that the sheet displays.  
- For each of those curves a little circle was drawn at a point on the curve; the curve number is written at the centre of the circle.  
- A leader (arrow) originates at the circle and points to the corresponding curve.

| # | Tool | Important arguments |

*(The `curves` arrays contain the indices of the curves that each sheet shows; they are determined from the results of the three `find_entities` calls. In a real run the indices would be extracted from those results.)*

**What caused confusion / required work‑arounds**

- The engine does not expose a direct API to obtain the curve indices of “visible” curves on a sheet; we had to query the sheet’s view (`find_entities` with `visible_on`) and then pick the `anchor.curve` field from each hit.  
- The `place_callout` command creates a leader **and text**. Because the number is already inside the circle, we passed an empty string for `content` so that only the arrow appears.  
- Setting a reasonably small circle radius (0.3 ft) was important; a larger radius would crowd the number.  

No errors were reported, and all objects appear in the model and the three sheets as described.
