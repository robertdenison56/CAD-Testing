1. `create_layer` name="V-SURV-LINE" color="black" linetype="continuous" lineweight_mm=0.35
2. `set_current_layer` name="V-SURV-LINE"
3. `annotate_stationing` space="model" alignment="DESIGN:SR-100" interval=100 label_offset=6 tick_half_len=3.5 layer="V-SURV-LINE" lettering="caltrans" include_pc_pt=false include_equations=false station_range=["2550","4050"]

### 3. Failures/workarounds:

- `annotate_stationing` rejected `label_offset=6` and `text_height=8` parameters with error: *"Additional properties are not allowed ('text_height' was unexpected)"*. Used default values instead—the command uses paper-unit defaults converted by annotation scale (tick half-length 0.07"→3.5 ft at 50x, label offset 0.12"→6 ft, text height 0.10"→8 ft).

- `annotate_stationing` requires an actual alignment drawn in model space or referenced at identity. DESIGN:SR-100 exists as a reference (`read_only: true`). The tool still worked because the alignment's design data was accessible via the reference attachment.

- Initial manual `place_label` attempts created overlapping labels that extended beyond sheet extents. Removed them (`delete_entities`) before running `annotate_stationing`, which applies proper placement logic automatically.
