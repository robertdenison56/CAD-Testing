1. **What you created and drew:**
    *   **Design Model (`ELM-AVE`):** A horizontal alignment starting at N 3000.00, E 1000.00, with three sections:
        *   Tangent 1 (PI to PI-2): S 80°00'00" E for 800.00 ft.
        *   Curve 1 (at PI-2): Deflects 40°00'00" Left on a 500 ft radius over 700.00 ft.
        *   Tangent 2 (PI-2 to PI-3): Deflects 25°00'00" Right on a 700 ft radius over 600.00 ft.
    *   **Layers:** `align_MAIN` (centerline), `rd_EP` (pavement edges, $\pm 11$ ft offsets), `rd_ES` (shoulder outside edges, $-16$ ft and $16$ ft offsets).
    *   **Annotations:** Stationing labels placed every 100 ft along the centerline.
    *   **Sheet (`C-101`):** Created as an ANSI D sheet with a single viewport (`VP-001`) at a scale of 1" = 100', covering the entire modeled design geometry, including shoulders. The title block was populated with "ELM AVE", "ROADWAY PLAN", and "1\" = 100'".

2. **The tool calls that mattered, in order:**
    *   `create_alignment`: Defines the alignment name `ELM-AVE` using the specified legs and bearings. (Start: [1000, 3000]; Legs: S 80° E 800; 40 L R=500 700; 25 R R=700 600).
    *   `draw_alignment`: Draws the centerline geometry on layer `align_MAIN`.
    *   `draw_offset`: Creates the pavement edges (11 ft) using offsets $\pm 11$ ft from the alignment on layer `rd_EP`. (The engine interpreted the list $[-11, 11]$ as drawing both sides).
    *   `draw_offset`: Draws the outer left shoulder edge ($-16$ ft offset) on layer `rd_ES`.
    *   `draw_offset`: Draws the outer right shoulder edge ($16$ ft offset) on layer `rd_ES`.
    *   `annotate_stationing`: Labels stations every 100 ft along the centerline.
    *   `create_sheet`: Sets up the sheet container `C-101` (ANSI D).
    *   `create_viewport`: Creates the view window (`VP-001`) on `C-101` set to a 1" = 100' scale, viewing the entire model area.
    *   `fill_title_block`: Populates the title block fields for "ELM AVE", "ROADWAY PLAN", and "1\" = 100'".

3. **Anything that failed, confused you, or that you had to work around:**
    The main confusion point was the repeated execution of commands which resulted in warnings/errors because entities were already created (e.g., `ELM-AVE` alignment being created multiple times, and offset lines being drawn multiple times). The tool calls for offsets required manual adjustment because the schema rejected extra parameters like `space` or `side`, forcing me to call `draw_offset` sequentially for each side ($\pm 16$ ft) even though one offset call could theoretically handle all geometry.

    *   **Error Handling:** I encountered multiple instances of: `"Additional properties are not allowed ('side', 'space' were unexpected)"` when using `draw_offset`. I had to remove the superfluous parameters (`space`, `side`) and rely solely on the core required parameter (`offsets`).
    *   **Redrawing:** The tool successfully warned/reported that offsets (like those for $16$ ft) already existed, but since the goal was a clean final state, subsequent calls were necessary to ensure all elements were present or updated.
