I placed a callout annotation ("SR-100 Centerline") on sheet `C-103`. It points at an element of the "SR-100" centerline (specifically the entity with ID `DESIGN:LN-003`).

*   `place_callout{alignment: "DESIGN:SR-100", content: "SR-100 Centerline", space: C-103, target_entity: "DESIGN:LN-003", position: [2, 8]}`: This successfully placed the callout using the identified entity ID and its parent alignment.

*   **Initial Confusion:** I struggled with the correct usage of `target_anchor` vs `target_entity`. The API documentation suggests prioritizing one over the other.

    *   The second attempt (using only `alignment` and `content`) failed because the required `position` parameter was missing.
*   **Workaround:** I successfully located a representative centerline entity ID (`DESIGN:LN-003`) by first running `find_entities` filtered by what is visible on `C-103`. Then, I used this concrete `target_entity` ID in the final `place_callout` call, which required me to supply an arbitrary but readable position (`[2, 8]`) for the text.
