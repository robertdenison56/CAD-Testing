3. Anything that failed, confused you, or that you had to work around -- quote error messages.
The core difficulty is the inability of `place_dimension` to take an alignment name and a station/offset combination (e.g., "at 17+00, offset -12") and dimension multiple segments across that point. The tool requires the boundary entities to be pre-drawn and passed as `of_entity`.

The error messages confirm this limitation:
*   **`station_to_xy` failed:** `"message": "no alignment named 'SR-100'", "hint": "this document owns no alignments, but its references carry ['DESIGN:SR-100'] -- name one of those to read its design"` (This showed that the reference name `DESIGN:SR-100` must be used, not just the segment name).
*   **`place_dimension` failed repeatedly:** `"message": "no entity 'DESIGN:SR-100' to measure (of_entity)", "hint": "find_entities and hit_test return ids; elements of an attached reference are 'REFNAME:ID'"}`. This error confirms that the tool expects a drawn element ID, not just the design data name (`DESIGN:SR-100`) when using `of_entity`.

To achieve this dimensioning, I would first need to draw the cross-section geometry (four lines/polylines) at 17+00 on sheet C-101 and assign them IDs. Then, I could use `place_dimension` sequentially for each segment using its respective ID as `of_entity`.
