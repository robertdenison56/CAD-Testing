  1 [1000 , 3000] (ft) – start

* **Stationing labels** – ticks & labels every 100 ft on the default tick/label layers (same layers as the centerline by default).

**Issues / work‑arounds**

* No arithmetic helpers exist, so all coordinate calculations (e.g., converting bearings, curve geometry) were done manually.  
* The `annotate_stationing` command expects either `path_ids` **or** an `alignment`. Supplying both would raise an error, so I left `path_ids` empty and relied on the alignment‑mode path.  
* All layers were created explicitly before any drawing; otherwise the draw commands would have failed with “layer not found”.  

The model now contains the alignment, its centerline, pavement edges, shoulder edges, and 100‑ft station labels as requested.
