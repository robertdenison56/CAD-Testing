**Issues / work‑arounds**

- The first attempt to create the layer used an invalid linetype `"solid"`; the engine only accepts the predefined linetype set (`continuous`, `dashed`, etc.). Switched to `"continuous"` and the layer was created successfully.  

**Arithmetic performed (by hand)**

  - ΔY = 60 sin 60° ≈ 51.962 ft → B = (1500+30, 1200+51.962) = (1530, 1251.962)  

- Right‑hand side (40 ft, S 60° E, i.e., bearing 120°):  
  - ΔX = 40 cos (‑30°) = 34.641 ft  
  - ΔY = 40 sin (‑30°) = –20 ft  

- Point C = B + (34.641, ‑20) = (1564.641, 1231.962)  
- Point D = A + (34.641, ‑20) = (1534.641, 1180)
