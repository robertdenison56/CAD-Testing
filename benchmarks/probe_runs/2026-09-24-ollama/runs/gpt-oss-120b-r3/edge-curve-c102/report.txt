**What was placed**  
- A callout (leader + text) on sheet **C‑102** (paper‑space).  
- The leader points at the curved pavement edge **DESIGN:AR‑003** (the left‑hand offset arc of SR‑100, shown through viewport VP‑002).

**Tool calls that mattered (in order)**  

1. `find_entities` – located the curved edge on the sheet:  
   ```json
   {
     "layer":"V-ROAD-EOP",
     "type":"arc",
     "visible_on":"C-102"
   }
   ```  
   (returned `DESIGN:AR-003` with sheet_point ≈ [3.8355, 7.5228]).

2. `place_callout` – created the callout:  
   ```json
   {
     "space":"C-102",
     "target_entity":"DESIGN:AR-003",
     "at":"mid",
     "position":[4.3355,8.0228],
     "content":"Pavement Edge",
     "layer":"V-ANNO-TEXT",
     "style":"STANDARD"
   }
   ```

**Issues / work‑arounds**  
- No errors occurred. The only preparatory step was using `find_entities` to obtain a good text‑position (sheet_point + 0.5 in each direction) so the callout does not overlap the geometry.
