**What was placed**  
- A callout (leader + text) on sheet **C‑103**. The text “SR‑100 CENTERLINE” points at the design‑reference line entity **DESIGN:LN‑003** (the SR‑100 centerline) as seen through viewport **VP‑003**.

**Tool calls that mattered (in order)**  
1. `find_entities` – located the centerline line on layer V‑ALIGN‑CNTR visible on sheet C‑103 (returned id DESIGN:LN‑003).  
2. `place_callout` – created the callout on sheet C‑103, pointing at the found entity:  
   ```json
   {
     "space":"C-103",
     "target_entity":"DESIGN:LN-003",
     "at":"mid",
     "position":[18.5,16.2],
     "content":"SR-100 CENTERLINE",
     "height":0.12,
     "layer":"V-ANNO-TEXT",
     "style":"STANDARD"
   }
   ```

**Issues & work‑arounds**  
- The first attempt to call `place_callout` failed because the schema does not allow `halign`/`valign` parameters. These were removed, using only the required fields (`space`, `position`, `content`) plus optional `height`, `layer`, `style`, `target_entity`, and `at`. The call then succeeded.
