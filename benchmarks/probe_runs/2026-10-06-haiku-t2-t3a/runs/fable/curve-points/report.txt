3. Failures, confusion, workarounds

- No command failed and no warnings were returned.
- Expected limitation: the alignment is referenced, so place_label was unusable. resolve_anchor said: "place_label cannot anchor to a referenced alignment; call it out with place_callout (target_anchor takes this anchor and alignment, from a sheet too), or copy the design into this document first". A leader callout is not how Caltrans letters a BC/EC station, and I did not want to copy the design into the sheet file, so I lettered with place_text on each sheet, letting station_to_xy (offset -16, sheet=...) supply the paper point and heading so no viewport arithmetic was done by hand. Consequence: these texts carry no design anchor for the verifier.
- Judgement call on "reading bottom to top" for the sloped tangent (heading 18.43°): the square line there is at 108.43° or -71.57°. I used 108.43° (heading + 90°) because it reads upward as the task states; the -71.57° alternative would read top to bottom even though it satisfies the usual "readable from the right" CAD rule.
- Judgement call on offset: used the engine's default label offset (16 ft / 0.32 in) left of the centerline with the text left-justified there, so the text runs outward from the centerline; it begins just outside the pavement edge and crosses the shoulder line, which is normal for square station lettering.
- The rd bridge omits inline image content from render_sheet ("[image content omitted by the bridge -- the file path is in the text above; open it to look]"), so I opened the three PNGs with the file reader to inspect them; that was a read only, no other program was run and nothing was edited or copied.
